## 1. 系统概述

### 1.1 系统简介

PP外贸订单管理系统是一款基于Tauri框架开发的桌面应用，专为中小型贸易企业设计。系统提供完整的订单管理、客户管理、产品管理、单据导出和数据分析功能，支持Windows操作系统。

**系统特点**：
- 🖥️ **桌面应用**：原生桌面体验，无需浏览器
- 💾 **本地存储**：数据存储在本地，安全可靠
- 🔄 **自动备份**：支持定时自动备份，防止数据丢失
- 📊 **数据分析**：提供丰富的统计图表和数据分析功能
- 🎨 **可视化模板**：支持自定义单据模板

### 1.2 主要功能模块

- **首页仪表盘**：统计卡片、趋势图表、快速操作、智能提醒
- **订单管理**：创建、编辑、查看、删除订单，支持订单状态跟踪和软删除恢复
- **客户管理**：客户信息维护、交易记录查询
- **产品管理**：产品信息维护、产品库管理、自动同步
- **文档中心**：模板管理、可视化编辑器、文档生成
- **单据导出**：支持商业发票、装箱单、销售确认书、生产通知单的PDF/Word/Excel导出
- **数据分析**：订单分析、客户分析、出口统计、趋势图表
- **系统设置**：公司信息配置、用户管理、数据库管理、自动备份配置、操作日志

### 1.3 产品类型说明

系统支持三种产品类型，每种类型有不同的字段和计算规则：

- **A类品**：包含标签重量、安全系数字段
- **B类品**：包含标签批号、标签说明（文本输入）字段
- **C类品**：包含标签说明（下拉选择）、唛头、包皮布字段

## 2. 登录与首页

### 2.1 登录页面

**访问方式**：
- **桌面应用**：启动应用程序，自动显示登录页面
- **开发模式**：访问 `http://localhost:5173/login.html`

**登录步骤**：
1. 输入用户名
2. 输入密码
3. 点击"登录"按钮

**登录结果**：
- ✅ **登录成功**：自动跳转到系统首页
- ❌ **登录失败**：显示错误提示，请检查用户名和密码

**注意事项**：
- 默认管理员账户：用户名和密码请咨询系统管理员
- 密码输入框支持显示/隐藏密码功能
- 登录状态会保持，关闭应用后重新打开无需重新登录（除非清除应用数据）
- 首次运行系统会自动初始化数据库

### 2.2 系统首页

**页面功能**：

#### 2.2.1 统计卡片

首页顶部显示关键业务指标卡片，包括：
- **订单总数**：所有订单的数量统计
- **总销售额（USD）**：所有订单的总金额
- **待发货订单**：状态为"已排产"的订单数量
- **已完成订单**：状态为"已完成"的订单数量
- **客户总数**：系统中的客户数量
- **产品总数**：产品库中的产品数量

**功能特点**：
- 卡片支持点击，可跳转到对应的列表页面
- 数据实时更新，自动刷新
- 渐变色彩设计，视觉效果美观

#### 2.2.2 快速操作

提供常用功能的快捷入口：
- **新建订单**：快速创建新订单
- **新建客户**：添加新客户
- **新增产品**：添加新产品到产品库
- **生成单据**：跳转到文档中心生成单据
- **订单列表**：查看所有订单
- **客户列表**：查看所有客户
- **交易统计**：查看数据分析页面
- **系统设置**：进入系统设置页面

#### 2.2.3 最近活动

- 显示最近5条订单记录
- 显示最近5条客户记录

- 显示操作时间和操作类型

#### 2.2.4 发货提醒

智能提醒即将到期的发货订单：
- 根据发货日期提前提醒（可配置提前天数）
- 显示订单号、客户名称、发货日期
- 支持点击查看订单详情
- 可配置提醒提前天数（默认7天）

#### 2.2.5 收款提醒

提醒已发货但未收款的订单：
- 显示已发货超过指定天数的订单
- 显示订单金额和发货天数
- 支持自定义提醒消息模板
- 可配置提醒阈值

#### 2.2.6 图表展示

- **订单趋势图**：显示最近30天的订单数量和金额趋势
- **订单状态分布**：饼图显示各状态订单的分布情况
- **客户交易排行**：柱状图显示交易额前10的客户

- **年度对比**：对比最近5年的订单数据
- **目的港分布**：显示订单目的港的分布情况
- **产品数量排行**：显示数量最多的前5个产品
- **箱型统计**：显示不同箱型的使用情况

**图表特点**：
- 支持点击图表跳转到详细分析页面
- 数据自动刷新
- 响应式设计，适配不同屏幕尺寸

#### 2.2.7 欢迎卡片

显示个性化欢迎信息：
- 根据时间显示问候语（早上好、下午好、晚上好）
- 显示当前日期和天气信息（如果可用）
- 显示系统提示和公告

**导航提示**：
- 首页提供到核心模块的快捷入口：订单管理、客户管理、产品管理、文档中心、数据分析、系统设置
- 左侧导航菜单可快速切换各个功能模块

## 3. 订单管理

### 3.1 订单列表页面

**访问路径**：左侧菜单 → "订单管理" → "订单列表"

**页面功能**：
- 显示所有订单的列表
- 支持订单筛选和搜索
- 支持订单状态查看和编辑
- 支持订单导出和删除

#### 3.1.1 订单列表显示

**显示字段**：
- 合同编号（红色加粗显示）
- 客户名称
- 订单日期
- 订单状态（带颜色标签）
- 订单金额（USD）
- 操作按钮

**订单状态颜色标识**：
- **已创建**：灰色渐变标签
- **已排产**：蓝色渐变标签
- **已发货**：橙色渐变标签
- **已完成**：绿色渐变标签

#### 3.1.2 筛选功能

**筛选字段**：
- **合同号**：输入合同号进行精确或模糊搜索
- **客户**：选择客户进行筛选
- **状态**：选择订单状态进行筛选
- **日期**：选择日期范围进行筛选
- **目的港**：输入目的港进行筛选

**操作步骤**：
1. 在筛选框中输入或选择筛选条件
2. 系统自动实时筛选（无需点击按钮）
3. 清空筛选条件可查看所有订单

#### 3.1.3 订单操作按钮

**查看订单**：
- 点击订单行的任意位置或"查看"按钮
- 跳转到订单编辑页面（只读模式）

**编辑订单**：
- 点击"编辑"按钮
- 跳转到订单编辑页面（可编辑模式）

**删除订单**：
- 点击"删除"按钮
- 弹出确认对话框
- 确认后删除订单（**不可恢复**）

**导出单据**：
- 点击"导出"按钮
- 选择要导出的单据类型（商业发票、装箱单、销售确认书、生产通知单）
- 选择导出格式（PDF或Word）
- 系统自动生成并下载文件

**批量操作**：
- 勾选多个订单的复选框
- 点击"批量删除"按钮可批量删除订单
- 点击"批量导出"按钮可批量导出订单

### 3.2 新建订单页面

**访问路径**：订单列表页面 → 点击"新建订单"按钮

**页面布局**：
- **顶部固定栏**：合同编号显示、产品类型切换按钮、操作按钮
- **订单信息区**：订单基本信息输入
- **产品明细区**：产品明细表格
- **生产通知信息区**：箱型、货箱数量、备注等信息

#### 3.2.1 订单信息填写

**必填字段**（标有红色星号*）：
- **客户**：选择或输入客户名称
  - 点击下拉框选择已有客户
  - 或直接输入新客户名称（系统会自动创建）
  - 如果客户名称已存在，系统会提示并自动关联

**可选字段**：
- **订单日期**：点击日期输入框，选择日期或手动输入（格式：YYYY-MM-DD）
- **合同编号**：系统自动生成下一个合同编号（格式：SC{年份}-{序号}）
  - 自动生成规则：查找当前年份最大合同编号，序号+1
  - 可以手动修改合同编号
  - 如果合同编号已存在，系统会提示并要求修改
- **订单号**：输入订单号（如：SO-2025-0001）
- **发货日期**：选择或输入发货日期
- **贸易术语**：选择CIF或CNR（默认CIF）
- **装运港**：输入装运港（默认：QINGDAO, CHINA）
- **目的港**：输入目的港
- **发票号**：输入发票号
- **提单号**：输入提单号
- **货运号**：输入货运号
- **订单状态**：选择订单状态（默认：已创建）

**金额字段**：
- **金额（USD）**：系统自动计算，显示为只读字段
  - 计算公式：所有产品明细的（数量 × 单价）之和
  - 实时更新：当产品明细变化时自动重新计算

#### 3.2.2 产品类型切换

**位置**：页面顶部固定栏，合同编号右侧

**按钮说明**：
- **A类品**：点击切换到A类品模板
- **B类品**：点击切换到B类品模板
- **C类品**：点击切换到C类品模板

**切换效果**：
- 产品明细表格表头会相应变化
- 显示/隐藏对应产品类型的特有字段
- 已填写的产品明细会保留通用字段数据

**自动切换规则**：
- 如果合同编号格式为 `SC{年份}-{序号}(NO.{订单号})`，系统会自动切换到C类品
- 例如：`SC2025-220(NO.28888)` 会自动切换为C类品

#### 3.2.3 产品明细管理

**添加产品明细**：
1. 点击"添加明细"按钮（页面右上角）
2. 系统在表格中新增一行
3. 填写产品信息

**产品明细字段说明**：

**通用字段**（所有产品类型都有）：
- **产品型号**：输入产品型号
  - 支持自动完成：输入时系统会显示匹配的产品型号列表
  - 点击列表中的产品，自动填充产品信息
  - 如果选择的产品类型与当前订单类型不匹配，会弹出确认对话框
    - 选择"是，切换产品类型"：切换订单产品类型并填充所有字段
    - 选择"否，保持当前类型"：保持当前类型，只填充通用字段
- **数量**：输入产品数量（必须为正数）
- **件数**：输入件数（必须为正数）
- **件数单位**：选择件数单位（件/托盘/捆包）
  - 影响皮重计算（见计算规则章节）
- **单价（USD）**：输入单价
- **实际重量**：输入实际重量（kg）
- **预估重量**：输入预估重量（kg）
  - 系统自动从产品库填充（如果产品库中有该产品）
- **清洁度**：选择清洁度（A/B/B+）
  - 系统自动从产品库填充（如果产品库中有该产品）

**A类品特有字段**：
- **标签重量**：输入标签重量（默认1000，浅绿色背景表示自动填充）
- **安全系数**：选择安全系数
  - 系统自动从产品库填充（如果产品库中有该产品）

**B类品特有字段**：
- **标签批号**：输入标签批号
  - 系统自动从产品库填充（如果产品库中有该产品）
- **标签说明**：输入标签说明（文本输入框）
  - 系统自动从产品库填充（如果产品库中有该产品）

**C类品特有字段**：
- **包皮布**：选择包皮布类型
  - 选择包皮布后，系统会自动填充或清空唛头字段
- **标签说明**：选择标签说明（下拉选择：KWS标签/CD3标签/F标签/无需标签）
  - 系统自动从产品库填充（如果产品库中有该产品）
- **唛头**：输入唛头信息
  - 根据包皮布选择自动填充或清空

**计算字段**（只读，系统自动计算）：
- **包装**：显示格式为"数量/件数 件数单位"
  - 计算公式：`包装 = 数量 ÷ 件数`（保留2位小数）
  - 例如：数量100，件数10，件数单位"件"，显示为"10.00 件"
- **预估总净重**：显示格式为数值（自动去除不必要的小数位）
  - 计算公式：`预估总净重 = 数量 × 预估重量`
  - 例如：数量100，预估重量1.5，显示为"150"

**操作字段**：
- **启用**：开关按钮，控制该产品明细是否参与计算
  - 关闭时，该产品明细不参与金额和重量计算
  - 默认开启

**产品明细操作**：
- **选择产品**：点击行首复选框选择产品
- **全选/取消全选**：点击表头复选框
- **删除所选**：选择产品后，点击"删除所选"按钮（页面右上角）
  - 弹出确认对话框
  - 确认后删除选中的产品明细
- **拖拽排序**：点击并拖拽行首的拖拽图标，可以调整产品顺序
- **编辑产品**：直接点击表格中的字段进行编辑

**合计行**：
- 显示所有启用产品的数量、件数、预估总净重合计
- 实时更新：当产品明细变化时自动重新计算

##### 错误提示样例与规则

- 件数单位缺失：
  - 提示内容："请为所有产品选择件数单位（件/托盘/捆包）"
  - 行定位：系统会标记未选择件数单位的产品行（红色边框或高亮）
  - 影响：包装字段不显示；皮重计算按 0 处理；保存校验不通过

- 实际重量为空：
  - 提示内容："该产品未填写实际重量，装箱单净重将为空"
  - 影响：装箱单中的净重不计算，毛重与净重合计不包含该行
  - 规则说明：不使用预估重量作为净重替代；仅在填写实际重量后参与净重/毛重计算

#### 3.2.4 生产通知信息

**箱型选择**：
- 选择箱型：20GP / 40GP / 40HC / 45HQ / L-107 / 其他
- 如果选择"其他"，会显示"箱型说明"输入框
- 如果选择其他箱型，会显示"箱型体积"输入框（必填）

**货箱数量**：
- 选择货箱数量（下拉选择）

**备注信息**：
- **唛头**：输入唛头信息（C类品会根据包皮布自动填充）
- **备注**：输入备注信息

#### 3.2.5 保存订单

**保存按钮**：页面右上角"保存订单"按钮

**保存前验证**：
- 客户必须选择或输入
- 产品明细至少需要一条
- 所有产品的件数单位必须选择
- 如果验证失败，会显示错误提示

**错误提示一览**：
- 必填项缺失：客户未选择或输入、产品明细为空
- 类型不匹配：选择的产品类型与订单当前产品类型不一致（会提供切换或保持的确认）
- 件数单位缺失：未选择件数单位（件/托盘/捆包）

**保存结果**：
- ✅ **保存成功**：显示成功提示，自动跳转到订单列表页面
- ❌ **保存失败**：显示错误提示，请检查输入数据

**草稿保存**：
- 系统会自动保存草稿到浏览器本地存储
- 下次打开新建订单页面时，可以选择恢复草稿

#### 3.2.6 返回按钮

**返回按钮**：页面右上角"返回"按钮

**功能**：
- 点击后返回订单列表页面
- 如果有未保存的更改，系统会提示是否保存

### 3.3 编辑订单页面

**访问路径**：订单列表页面 → 点击订单的"编辑"按钮

**页面功能**：
- 与新建订单页面基本相同
- 自动加载订单数据
- 可以修改订单信息
- 保存后更新订单

**特殊说明**：
- 合同编号显示为只读（不可修改）
- 其他字段可以修改
- 保存后订单状态不会自动改变（除非导出单据）

## 4. 客户管理

### 4.1 客户列表页面

**访问路径**：左侧菜单 → "客户管理" → "客户列表"

**页面功能**：
- 显示所有客户的列表
- 支持客户搜索和筛选
- 支持客户添加、编辑、删除
- 支持查看客户交易记录

#### 4.1.1 客户列表显示

**显示字段**：
- 客户名称
- 客户地址
- 联系电话
- 邮箱地址

#### 7.3.1 自动备份配置

**功能说明**：
系统支持定时自动备份，确保数据安全。备份功能由Rust后端实现，即使主窗口关闭，只要程序在系统托盘运行，定时备份任务就会持续工作。

**配置步骤**：
1. 进入"数据库设置"页面
2. 找到"自动备份配置"区域
3. 开启"启用自动备份"开关
4. 选择"备份存放路径"（默认为 `D:\PP订单管理系统数据备份\`）
   - 点击"选择目录"按钮选择备份路径
   - 系统会自动创建目录（如果不存在）
5. 设置"执行频率"：
   - 每 6 小时（高频保护 - 适合业务量大）
   - 每 12 小时（标准保护 - 推荐）
   - 每 24 小时（每日快照）
   - 每 3 天（归档模式）
   - 每 7 天（归档模式）
6. 点击"保存自动备份配置"按钮

**备份特性**：
- **文件命名**：`erp_backup_yyyyMMdd_HHmmss.sqlite`（例如：`erp_backup_20260118_153000.sqlite`）
- **自动清理**：系统默认保留最近30份备份文件，超过数量的旧文件会被自动清理
- **完整性校验**：每次备份完成后，系统会进行静默的读取测试，确保备份文件非损坏状态
- **后台执行**：备份在后台静默执行，不会影响正常使用

**立即备份**：
- 点击"立即备份"按钮可执行一次即时的手动备份
- 备份完成后会显示备份文件路径

## 8. 计算规则详解

### 8.1 重量计算规则

#### 8.1.1 预估总净重计算

**公式**：`预估总净重 = 产品数量 × 单件预估重量`

**适用场景**：
- 订单录入时预估总净重的重量估算
- 产品明细表格中的"预估总净重"字段

**计算位置**：新建/编辑订单页面产品明细表

**显示格式**：
- 自动去除不必要的小数位
- 例如：100.0 显示为 100，150.5 显示为 150.5

**更新时机**：
- 数量变化时自动重新计算
- 预估重量变化时自动重新计算

#### 8.1.2 净重（NET WEIGHT）计算

**公式**：`净重 = 实际重量 × 数量`

**适用场景**：
- 装箱单（Packing List）文档中的净重计算

**计算规则**：
- 只使用实际重量进行计算
- 如果实际重量为空或未填写，净重显示为空
- 不再使用预估重量作为备选值

**显示格式**：`{数值} KGS`（如：1500 KGS）

**取整规则**：使用 `Math.round()` 四舍五入到整数

#### 8.1.3 皮重（TARE WEIGHT）计算

**公式**：根据件数单位计算

**计算规则**：
- **件数单位为"件"**：`皮重 = 0.25 × 件数数量`
- **件数单位为"托盘"**：`皮重 = 15 × 件数数量`
- **件数单位为"捆包"**：`皮重 = 10 × 件数数量`
- **件数单位未选择或为空**：`皮重 = 0`

**适用场景**：
- 装箱单文档中的皮重计算

**显示格式**：`{数值} KGS`（如：25 KGS）

**注意事项**：
- 件数单位必须正确选择，否则皮重计算会不准确
- 皮重计算基于件数，不是基于数量

#### 8.1.4 毛重（GROSS WEIGHT）计算

**公式**：`毛重 = 净重 + 皮重`

**前提条件**：
- 只有净重存在时才计算毛重
- 如果净重为空，毛重也显示为空

**适用场景**：
- 装箱单文档中的毛重计算

**显示格式**：`{数值} KGS`（如：1525 KGS）

#### 8.1.5 重量合计计算

**合计项目**：
- 净重合计：所有产品的净重之和
- 皮重合计：所有产品的皮重之和
- 毛重合计：所有产品的毛重之和

**计算规则**：
- 只计算"启用"状态的产品
- 如果某个产品的净重为空，不参与净重合计
- 毛重合计 = 净重合计 + 皮重合计

### 8.2 金额计算规则

#### 8.2.1 产品金额计算

**公式**：`产品金额 = 数量 × 单价`

**适用场景**：
- 产品明细中的金额计算
- 订单总金额计算的基础

**计算位置**：新建/编辑订单页面产品明细表

**更新时机**：
- 数量变化时自动重新计算
- 单价变化时自动重新计算

#### 8.2.2 订单总金额计算

**优先级1**：使用订单表中的 `totalUSD` 字段（如果存在）

**优先级2**：计算所有订单项金额之和
- **公式**：`总金额 = Σ(产品数量 × 产品单价)`
- 只计算"启用"状态的产品
- 如果某个产品的数量或单价为空，不参与计算

**显示位置**：
- 订单信息区的"金额（USD）"字段
- 订单列表中的"订单金额"列

**更新时机**：
- 产品明细变化时自动重新计算
- 保存订单时更新到数据库

### 8.3 包装计算规则

#### 8.3.1 包装数量计算

**公式**：`包装数量 = 数量 ÷ 件数`

**精度处理**：`Math.round(计算结果 × 100) ÷ 100`（保留2位小数）

**显示格式**：`{包装数量} {件数单位}`
- 例如：数量100，件数10，件数单位"件"，显示为"10.00 件"
- 例如：数量200，件数5，件数单位"托盘"，显示为"40.00 托盘"

**计算位置**：新建/编辑订单页面产品明细表的"包装"字段

**更新时机**：
- 数量变化时自动重新计算
- 件数变化时自动重新计算
- 件数单位变化时自动重新计算

**注意事项**：
- 件数必须为正数，否则包装计算会出错
- 如果件数为0或空，包装显示为空

### 8.4 计算触发机制

#### 8.4.1 自动计算触发

**触发条件**：
- **数量变化**：触发预估重量、包装数量、产品金额计算
- **重量变化**：触发预估重量计算
- **单价变化**：触发产品金额、订单总金额计算
- **件数变化**：触发包装数量计算
- **件数单位变化**：触发包装数量计算
- **产品启用/禁用**：触发订单总金额、合计行计算

**实时更新**：
- 所有计算都是实时的，无需手动刷新
- 计算结果立即显示在界面上

#### 8.4.2 计算前置条件

**必要字段**：
- **预估重量计算**：需要数量和预估重量
- **净重计算**：需要实际重量和数量
- **皮重计算**：需要件数和件数单位
- **毛重计算**：需要净重（自动计算）
- **产品金额计算**：需要数量和单价
- **包装计算**：需要数量、件数和件数单位

**数据验证**：
- **数量字段**：必须为正数（用于金额和重量计算）
- **件数字段**：必须为正数（用于包装计算）
- **单价字段**：必须为非负数（用于金额计算）
- **重量字段**：必须为非负数（用于重量计算）

## 9. 常见问题与技巧

### 9.1 常见问题

#### 9.1.1 软件无法启动？

**可能原因**：
- 没有安装Node.js
- 端口3000或5173被占用
- 依赖包未安装

**解决方法**：
1. 安装Node.js（版本16以上）：访问 https://nodejs.org 下载安装
2. 关闭占用端口的其他程序
3. 重新安装依赖：`npm install`
4. 重新启动软件

#### 9.1.2 数据丢失了怎么办？

**预防措施**：
- 定期备份 `data` 文件夹
- 使用系统提供的数据库备份功能
- 导出重要订单数据

**恢复方法**：
1. 进入"系统设置" → "数据库管理"
2. 选择备份文件恢复
3. 重启软件

#### 9.1.3 导出的PDF格式不对？

**解决方法**：
1. 使用"预览"功能检查格式
2. 确保订单信息完整
3. 尝试使用Chrome浏览器
4. 检查公司信息是否已配置

#### 9.1.4 重量数据不准确？

**解决方法**：
1. 检查产品的实际重量是否已填写
2. 确认件数单位设置正确（影响皮重计算）
3. 使用产品库统一管理重量信息
4. 定期校验和更新产品重量数据

#### 9.1.5 计算结果异常？

**解决方法**：
1. 检查输入数据的有效性（非负数、正整数等）
2. 确认必要字段已填写完整
3. 查看计算规则文档了解计算逻辑
4. 使用预览功能验证计算结果
5. 检查产品是否已启用（未启用的产品不参与计算）

#### 9.1.6 产品型号自动完成不工作？

**解决方法**：
1. 检查产品库中是否有该产品
2. 尝试手动输入产品型号
3. 刷新页面重新加载产品数据
4. 检查浏览器控制台是否有错误信息

#### 9.1.7 订单保存失败？

**可能原因**：
- 客户未选择
- 产品明细为空
- 产品件数单位未选择
- 网络连接问题

**解决方法**：
1. 检查错误提示信息
2. 确保必填字段已填写
3. 检查网络连接
4. 刷新页面后重试

### 9.2 使用技巧

#### 9.2.1 提高工作效率

**产品型号自动完成**：
- 输入产品型号时，系统会自动提示历史记录
- 点击提示列表中的产品，自动填充产品信息
- 如果产品类型不匹配，系统会提示是否切换产品类型

**批量操作**：
- 选中多个订单可以批量删除或导出
- 选中多个产品可以批量编辑或删除

**快捷筛选**：
- 使用筛选功能快速找到需要的订单
- 支持多条件组合筛选

**定期备份**：
- 养成定期备份数据的习惯
- 使用系统提供的备份功能

**产品库管理**：
- 统一管理产品信息，提高录入效率
- 从订单同步产品，自动维护产品库

#### 9.2.2 数据管理建议

**客户信息标准化**：
- 统一客户名称格式，避免重复录入
- 及时更新客户信息

**产品编码规范**：
- 建立统一的产品型号编码规则
- 保持产品型号的唯一性

**订单编号规则**：
- 制定清晰的订单编号规则
- 使用系统自动生成的合同编号

**定期整理**：
- 定期清理测试数据和无效订单
- 保持数据的整洁和准确性

**重量数据维护**：
- 及时更新产品的实际重量信息
- 确保重量数据的准确性

#### 9.2.3 计算准确性提升

**完善实际重量**：
- 确保产品的实际重量字段填写完整
- 实际重量用于净重和毛重计算

**验证计算结果**：
- 使用预览功能检查计算是否正确
- 对比预估重量和实际重量

**统一单位规范**：
- 确保件数单位设置正确（影响皮重计算）
- 保持单位使用的一致性

**数据一致性检查**：
- 定期检查产品库与订单数据的一致性
- 及时同步产品信息

#### 9.2.4 产品类型使用建议

**A类品**：
- 适用于需要安全系数和标签重量的产品
- 常用于标准化的产品

**B类品**：
- 适用于需要标签批号和标签说明的产品
- 标签说明为文本输入，可以自由填写

**C类品**：
- 适用于需要唛头和包皮布信息的产品
- 标签说明为下拉选择，选项固定
- 合同编号格式特殊时自动切换为C类品

**产品类型切换**：
- 在订单编辑页面可以随时切换产品类型
- 切换时已填写的通用字段会保留
- 选择产品时如果类型不匹配，系统会提示是否切换
