### 快速开始


## 数据库管理

### 数据库位置

| 环境 | 数据库路径 |
|------|------------|
| 开发环境 | `%APPDATA%\com.pp.ordermanagement\data\erp.sqlite` |
| 生产环境 | `%APPDATA%\com.pp.ordermanagement\data\erp.sqlite` |

### 数据库备份

#### 自动备份（推荐）

系统支持定时自动备份，配置方式：
1. 进入系统设置 → 数据库设置
2. 开启"启用自动备份"
3. 设置备份路径（默认：`D:\PP订单管理系统数据备份\`）
4. 设置备份频率（6小时/12小时/24小时/3天/7天）
5. 点击"保存自动备份配置"

**自动备份特性**：
- 后台静默执行，不影响正常使用
- 系统托盘运行时也会执行备份
- 自动保留最近30份备份文件
- 备份文件命名：`erp_backup_yyyyMMdd_HHmmss.sqlite`

#### 手动备份

**方式一：通过系统界面**
1. 进入系统设置 → 数据库设置
2. 点击"立即备份"按钮
3. 选择备份文件保存位置

**方式二：使用备份脚本**
```bash
# 使用备份脚本
scripts\utils\backup-database.bat
```

备份文件保存在：`%APPDATA%\com.pp.ordermanagement\backups\`

### 数据库迁移

如果需要从旧版本迁移数据库：

```bash
# 使用迁移脚本
scripts\utils\migrate-database-to-appdata.bat
```

### 数据库路径检查

```bash
# 检查当前数据库路径
scripts\utils\check-database-path.bat
```

## 常见问题

### 启动问题

#### Q: 端口 3000 或 5173 被占用

**解决方案**：

```bash
# 查看占用端口的进程
netstat -ano | findstr :3000
netstat -ano | findstr :5173

# 结束进程（替换 PID 为实际进程ID）
taskkill /F /PID <PID>
```

#### Q: 依赖安装失败

**解决方案**：

```bash
# 清理缓存
npm cache clean --force

# 删除 node_modules 并重新安装
rmdir /s /q node_modules
npm install
```

#### Q: Tauri 编译失败

**解决方案**：

```bash
# 更新 Rust 工具链
rustup update

# 清理 Tauri 编译缓存
scripts\utils\clear-cache.bat

# 重新构建
npm run tauri:build
```

### 运行问题

#### Q: 数据库连接失败

**解决方案**：

1. 检查数据库路径是否正确
2. 确保数据目录存在
3. 检查文件权限

```bash
# 检查数据库路径
scripts\utils\check-database-path.bat

# 健康检查
scripts\utils\health-check.bat
```

#### Q: 文件保存功能不工作

**说明**：在全栈开发模式（浏览器）中，文件保存会降级为浏览器下载。要使用原生文件对话框，请使用 Tauri 开发模式或生产版本。

#### Q: 自动备份不工作

**解决方案**：

1. **检查是否在 Tauri 模式**：
   - 自动备份功能仅在 Tauri 模式下可用（桌面应用）
   - 浏览器开发模式下无法使用自动备份

2. **检查备份配置**：
   - 进入系统设置 → 数据库设置
   - 确认"启用自动备份"已开启
   - 确认备份路径已设置且有效

3. **检查系统托盘**：
   - 确保应用在系统托盘运行（最小化到托盘）
   - 自动备份在后台运行，需要程序保持运行状态

4. **查看日志**：
   - 检查应用日志文件：`%APPDATA%\com.pp.ordermanagement\logs\app.log`
   - 查看备份相关日志信息

#### Q: 登录失败 / 忘记密码

**解决方案**：

```bash
# 重置管理员密码
scripts\utils\修复管理员密码.ps1
```

默认管理员账户：
- 用户名：`admin`
- 密码：`admin123`

## 架构说明

### 混合后端架构

本项目采用 Rust + Node.js 混合后端架构：

**Rust 后端（Tauri Commands）**：
- 数据库操作（使用 rusqlite）
- 文件系统操作
- 系统原生功能（对话框、托盘等）
- 用户认证和会话管理
- 自动备份功能

**Node.js 后端（Express Server）**：
- PDF 导出（使用 Puppeteer）
- Word 导出（使用 docx、html-to-docx）
- Excel 导出（使用 xlsx、exceljs）
- 文档模板渲染
- 复杂业务逻辑处理

**数据共享**：
- Rust 和 Node.js 后端共享同一 SQLite 数据库
- 数据库路径：`%APPDATA%\com.pp.ordermanagement\data\erp.sqlite`
- 通过环境变量 `DB_PATH` 确保路径一致

### 开发模式对比

| 特性 | 浏览器开发模式 | Tauri 开发模式 | 生产版本 |
|------|--------------|---------------|----------|
| 数据库操作 | Node.js 后端 | Rust 后端 | Rust 后端 |
| 文件保存 | 浏览器下载 | 原生对话框 | 原生对话框 |
| 系统托盘 | ❌ | ✅ | ✅ |
| 自动备份 | ❌ | ✅ | ✅ |
| 开发工具 | 浏览器 DevTools | Tauri DevTools | ❌ |
| 启动速度 | 快（5-10秒） | 慢（15-30秒首次） | N/A |
