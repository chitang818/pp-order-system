# PP订单管理系统 - 密码修复工具使用说明

## 快速使用

1. **关闭应用**
   - 完全退出 PP订单管理系统

2. **运行脚本**
   - 找到文件：`修复管理员密码.ps1`
   - **右键点击** → 选择 **"使用 PowerShell 运行"**
   - 如果没有此选项，按住 Shift 键再右键，选择 **"在此处打开 PowerShell 窗口"**，然后输入：
     ```powershell
     .\修复管理员密码.ps1
     ```

3. **等待完成**
   - 脚本会自动：
     - ✓ 检查数据库
     - ✓ 创建备份
     - ✓ 下载 SQLite 工具
     - ✓ 重置密码
     - ✓ 验证结果

4. **重启登录**
   - 启动应用
   - 使用 `admin` / `admin123` 登录

## 如果遇到执行策略错误

如果提示 "无法加载，因为在此系统上禁止运行脚本"：

1. 以**管理员身份**打开 PowerShell
2. 执行：
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```
3. 输入 `Y` 确认
4. 再次运行修复脚本

## 脚本功能

- ✅ 自动下载 SQLite 工具（无需手动下载）
- ✅ 自动备份数据库
- ✅ 安全重置密码
- ✅ 失败自动回滚
- ✅ 详细的执行日志

## 备份位置

脚本会自动创建备份，位置：
```
C:\Users\chitang\AppData\Roaming\com.pp.ordermanagement\data\erp.sqlite.backup-YYYYMMDD-HHMMSS
```

## 故障排除

### 问题1：下载失败
**解决**：手动下载 SQLite 工具
1. 访问：https://www.sqlite.org/download.html
2. 下载 "sqlite-tools-win-x64-*.zip"
3. 解压到：`C:\Users\chitang\AppData\Local\Temp\sqlite_tools\`
4. 重新运行脚本

### 问题2：找不到数据库
**解决**：确保应用至少运行过一次，生成了数据库文件

### 问题3：权限不足
**解决**：以管理员身份运行 PowerShell
