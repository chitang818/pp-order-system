# PP 外贸订单管理系统 (PP Order System)

> 一个现代化、跨平台的外贸订单管理解决方案，专为中小型出口企业打造，支持桌面端（Tauri）和 Web 端双模式运行。

## 📖 项目简介

PP 外贸订单管理系统是一套集成了订单追踪、单证自动化、财务统计和客户管理的一体化外贸 ERP 系统。它采用先进的前后端分离架构（Vue
3 +
Node.js），结合 Tauri 技术，既拥有 Web 应用的灵活性（多人协作、远程访问），又具备桌面应用的系统级集成能力（本地文件操作、高性能体验）。

系统旨在解决外贸流程中“单证制作繁琐”、“订单状态跟踪难”、“财务数据统计滞后”等核心痛点。

## 🌟 核心功能

### 1. 📊 智能仪表盘 (Dashboard)

- **实时数据概览**：首页直观展示当日/当月订单数、待出运订单、总销售额及利润统计。
- **可视化图表**：集成 Chart.js，动态展示出口趋势图、客户区域分布图。
- **快捷入口**：常用功能（新建订单、发票生成）一键直达。

### 2. 🚢 订单全流程管理 (Order Management)

- **全生命周期追踪**：从 PI (形式发票) -> SC (销售确认书)
  -> 生产 -> 出运 -> 收汇，全链路状态管理。
- **多维度检索**：支持按合同号、客户、日期、出运状态快速筛选。
- **智能填充**：内置历史数据记忆功能，自动填充常用目的港、中转港及交易条款。
- **货代管理 (Forwarders)**：独立模块管理货代信息，支持订单绑定指定货代。

### 3. 📄 单证自动化中心 (Document Center)

不再因为调整一个数据而修改三份文档！系统支持一键生成全套出口单据：

- **商业发票 (Commercial Invoice)**：自动计算金额、总价，支持多种币种格式。
- **装箱单 (Packing
  List)**：自动汇总箱数、毛净重、体积 (CBM)，支持混装/单装逻辑。
- **销售合同 (Sales Confirmation)**：一键生成标准外贸销售合同，支持自定义条款。
- **PDF 导出**：所有单证均可直接预览并导出为专业 PDF 格式，支持公司抬头 (Letterhead) 定制。

### 4. 📦 产品与库存 (Products & Inventory)

- **产品库管理**：集中管理 SKU、中英文品名、HS编码、材质、规格等详细信息。
- **图片管理**：支持产品图片上传与预览，生成的单证可选择是否附带图片。
- **价格体系**：记录不同客户的历史报价，辅助快速报价。

### 5. 👥 客户管理 (CRM)

- **客户档案**：详细记录客户公司信息、联系人、收货地址、唛头要求等。
- **交易历史**：快速查看某客户的历史订单记录与偏好。

### 6. 💰 财务与统计 (Finance & Statistics)

- **利润核算**：基于汇率、采购成本、海运费等自动计算单笔订单利润与利润率。
- **收汇管理**：追踪定金、尾款到账情况，逾期自动提醒。
- **报表导出**：支持导出 Excel 格式的月度/季度销售报表。

### 7. ⚙️ 系统与其他 (System & Tools)

- **双模式运行**：
  - **Web 模式**：适合局域网部署，多端同时访问。
  - **Tauri 桌面模式**：适合单机高性能使用，支持开机自启、系统托盘。
- **数据安全**：所有数据存储在本地 AppData 目录 (SQLite)，支持自动/手动备份，无需担心云端数据泄露。
- **跨平台**：完美支持 Windows 10/11, macOS, Linux。
- **浏览器自动化**：内置 Puppeteer 脚本，可扩展用于抓取汇率或对接其他网页系统。

## 🛠️ 技术栈

| 领域           | 技术/库                    | 说明                           |
| -------------- | -------------------------- | ------------------------------ |
| **前端**       | Vue 3 + Vite               | 核心框架，极其流畅的 SPA 体验  |
| **UI 组件**    | TailwindCSS + Element Plus | 现代化、响应式的界面设计       |
| **后端**       | Node.js + Express          | 稳定高效的 RESTful API 服务    |
| **数据库**     | SQLite3                    | 轻量级、无服务器的文件型数据库 |
| **桌面运行时** | Tauri v2 (Rust)            | 极小体积、极高性能的桌面封装   |
| **PDF 生成**   | Puppeteer / PDFKit         | 像素级完美的单证生成           |

## 🚀 快速开始

本项目提供了高度自动化的开发脚本，位于 `scripts/` 目录。

### 环境要求

- **Node.js**: 18.0 或更高版本
- **Rust**: 仅 Tauri 开发模式需要 (建议使用 rustup 安装)
- **包管理器**: npm 或 yarn

### 1. 安装依赖

```bash
npm install
```

### 2. 启动日常开发 (Web 模式)

使用我们的一键启动脚本，同时启动前端和后端服务：

```bash
# Windows
scripts\dev\快速启动.bat
```

_启动后浏览器将自动打开 http://localhost:5173，后端运行在 3000 端口。_

### 3. 启动桌面应用开发

如果您需要测试本地文件读写、托盘等原生功能：

```bash
# Windows
scripts\dev\Tauri开发.bat
```

## 📂 项目结构概览

```
pp-order-system/
├── backend/                # Node.js 后端服务
│   ├── app.js              # 入口文件
│   ├── routes/             # API 路由 (auth, orders, products...)
│   └── db/                 # 数据库迁移与模型
├── frontend/               # Vue 3 前端应用
│   ├── src/
│   │   ├── views/          # 页面 (Dashboard, OrderEdit, Invoice...)
│   │   └── components/     # 公共组件
├── src-tauri/              # Rust 桌面主进程配置
├── scripts/                # 自动化脚本 (开发、构建、维护)
├── config/                 # 配置文件 (config.json)
└── data/                   # 数据库文件 (开发环境默认位置)
```

## 📦 构建与部署

我们提供了一键打包脚本，自动处理版本号增加、构建前端、编译后端和打包安装包。

```bash
scripts\build\一键打包.bat
```

_构建产物将输出在 `src-tauri/target/release/bundle/nsis/` (Windows)_
