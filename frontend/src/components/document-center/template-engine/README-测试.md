# 🚀 快速开始测试

## ⚠️ 重要：必须使用本地服务器

**不能直接双击HTML文件！** 浏览器不允许通过 `file://` 协议加载ES模块。

## 最简单的启动方法

### Windows用户

**双击运行：** `快速启动测试.bat`

或者手动运行：
```bash
npm run dev
```

### Mac/Linux用户

**运行：**
```bash
chmod +x 快速启动测试.sh
./快速启动测试.sh
```

或者手动运行：
```bash
npm run dev
```

## 访问测试页面

服务器启动后（通常是 `http://localhost:5173`），在浏览器中打开：

```
http://localhost:5173/src/components/document-center/template-engine/test.html
```

或使用独立版：

```
http://localhost:5173/src/components/document-center/template-engine/test-standalone.html
```

## 如果遇到问题

1. **确保已安装依赖**
   ```bash
   npm install
   ```

2. **检查端口是否被占用**
   - Vite默认使用5173端口
   - 如果被占用，会自动尝试其他端口
   - 查看终端输出的实际端口号

3. **查看浏览器控制台**
   - 按F12打开开发者工具
   - 查看Console标签页的错误信息
