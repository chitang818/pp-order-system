# 测试页面使用说明

## 问题：点击按钮无反应

如果点击"运行所有测试"按钮没有反应，可能是以下原因：

### 1. 模块导入路径问题

**解决方案：**
- 确保使用**本地开发服务器**运行（如 `npm run dev`）
- 不要直接双击HTML文件打开（file://协议不支持ES模块）

### 2. 使用独立版测试页面

我已经创建了一个改进版本的测试页面：`test-standalone.html`

这个版本会：
- 自动尝试多个路径加载模块
- 显示详细的加载错误信息
- 提供更好的错误提示

### 3. 在浏览器控制台直接运行

如果页面无法加载模块，可以在浏览器控制台（F12）中直接运行：

```javascript
// 方式1: 动态导入
import('./test-runner.js')
  .then(module => {
    console.log('模块加载成功');
    const result = module.runTests();
    console.log('测试结果:', result);
  })
  .catch(error => {
    console.error('模块加载失败:', error);
  });

// 方式2: 如果使用绝对路径
import('/src/components/document-center/template-engine/test-runner.js')
  .then(module => module.runTests());
```

### 4. 检查浏览器控制台

打开浏览器开发者工具（F12），查看：
- Console标签页的错误信息
- Network标签页，看是否有404错误（文件未找到）

### 5. 验证文件是否存在

确保以下文件都存在：
- `test-runner.js`
- `parser/tokenizer.js`
- `parser/template-parser.js`
- `resolver/variable-resolver.js`
- `resolver/filter-registry.js`
- `resolver/data-accessor.js`
- `utils/cache.js`

## 快速测试方法

### 方法1: 使用Vite开发服务器

```bash
# 如果项目使用Vite
npm run dev

# 然后在浏览器中打开
# http://localhost:5173/src/components/document-center/template-engine/test.html
```

### 方法2: 使用Python简单服务器

```bash
# 在项目根目录运行
python -m http.server 8000

# 然后在浏览器中打开
# http://localhost:8000/frontend/src/components/document-center/template-engine/test.html
```

### 方法3: 直接在控制台测试单个组件

```javascript
// 测试Tokenizer
import('./parser/tokenizer.js')
  .then(module => {
    const tokens = module.Tokenizer.tokenize('{{order.contractNo}}');
    console.log('Tokens:', tokens);
  });

// 测试TemplateParser
import('./parser/template-parser.js')
  .then(module => {
    const ast = module.TemplateParser.parse('{{order.contractNo}}');
    console.log('AST:', ast);
  });
```

## 常见错误及解决方案

### 错误1: Failed to load module script

**原因：** 使用file://协议打开HTML文件

**解决：** 使用本地服务器运行

### 错误2: Cannot find module

**原因：** 文件路径不正确

**解决：** 
- 检查文件是否存在于指定路径
- 检查导入路径是否正确
- 尝试使用绝对路径

### 错误3: CORS policy

**原因：** 跨域问题

**解决：** 使用本地服务器运行，不要直接打开HTML文件

## 推荐测试流程

1. **启动开发服务器**
   ```bash
   npm run dev
   ```

2. **打开测试页面**
   - 访问：`http://localhost:5173/src/components/document-center/template-engine/test-standalone.html`
   - 或：`http://localhost:5173/src/components/document-center/template-engine/test.html`

3. **点击"运行所有测试"按钮**

4. **查看结果**
   - 页面上的输出区域
   - 浏览器控制台
