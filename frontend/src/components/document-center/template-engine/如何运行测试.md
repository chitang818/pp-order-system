# 如何运行测试

## ⚠️ 重要提示

**不能直接双击HTML文件打开！** 必须使用本地开发服务器运行。

## 快速开始

### 方法1: 使用Vite开发服务器（推荐）

1. **打开终端，进入项目根目录**

2. **启动开发服务器**
   ```bash
   npm run dev
   ```

3. **等待服务器启动**，你会看到类似这样的输出：
   ```
   VITE v7.x.x  ready in xxx ms
   
   ➜  Local:   http://localhost:5173/
   ➜  Network: use --host to expose
   ```

4. **在浏览器中打开测试页面**
   ```
   http://localhost:5173/src/components/document-center/template-engine/test.html
   ```
   或
   ```
   http://localhost:5173/src/components/document-center/template-engine/test-standalone.html
   ```

5. **点击"运行所有测试"按钮**

### 方法2: 使用Python简单服务器

如果项目没有配置Vite，可以使用Python：

1. **打开终端，进入项目根目录**

2. **启动Python服务器**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # 或 Python 2
   python -m SimpleHTTPServer 8000
   ```

3. **在浏览器中打开**
   ```
   http://localhost:8000/frontend/src/components/document-center/template-engine/test.html
   ```

### 方法3: 使用Node.js http-server

1. **安装http-server**（如果还没有）
   ```bash
   npm install -g http-server
   ```

2. **启动服务器**
   ```bash
   http-server -p 8000
   ```

3. **在浏览器中打开**
   ```
   http://localhost:8000/frontend/src/components/document-center/template-engine/test.html
   ```

## 为什么不能直接打开HTML文件？

现代浏览器出于安全考虑，不允许通过 `file://` 协议加载ES模块。ES模块必须通过HTTP/HTTPS协议加载。

## 验证服务器是否运行

打开浏览器，访问：
- `http://localhost:5173/` （Vite默认端口）
- 或 `http://localhost:8000/` （其他服务器）

如果能看到项目页面，说明服务器运行正常。

## 常见问题

### Q: npm run dev 报错？
A: 确保已安装依赖：
```bash
npm install
```

### Q: 端口被占用？
A: Vite会自动尝试其他端口，或者手动指定：
```bash
npm run dev -- --port 3000
```

### Q: 测试页面404？
A: 检查文件路径是否正确，确保文件存在于：
```
frontend/src/components/document-center/template-engine/test.html
```
